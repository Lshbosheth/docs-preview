# 文档站界面升级方案

更新日期：2026-06-12

## 目标

把当前 VitePress 文档站从默认样式升级成更耐看的“小清新”风格。

这里的小清新不是甜腻、幼稚、网红风，而是：

- 干净
- 轻盈
- 有呼吸感
- 适合长期阅读
- 中文文档看起来更舒服
- 技术内容仍然清楚、克制、专业

## 当前问题

现在页面能用，但视觉偏默认：

- 首页太像 VitePress 原始模板
- 颜色层次少
- 页面缺少文档站自己的气质
- 文章阅读区略单调
- 侧边栏和导航没有明显的“个人文档站”感觉
- 每日英语里的发音按钮已经有一点设计感，但整体页面没有跟上

## 设计方向

建议方向：**清爽白底 + 柔和青绿色点缀 + 轻微纸感 + 更舒服的中文排版**。

关键词：

- 清新，但不要满屏浅绿
- 温柔，但不要变成少女博客
- 轻量，但不要空得像没做设计
- 有个人感，但不要像营销落地页
- 适合技术文档、学习计划、每日英语长期共存

## 色彩建议

主色可以用偏青绿或蓝绿色，但控制使用面积：

- 品牌色：柔和青绿 / 松石绿
- 背景色：接近白色，略带冷调
- 辅助色：浅蓝灰、淡薄荷绿
- 文字色：深灰，不要纯黑
- 强调色只用于链接、按钮、当前导航、重点边框

避免：

- 大面积渐变
- 满屏绿色
- 高饱和荧光色
- 紫蓝渐变模板风
- 米黄复古风

## 页面结构建议

### 首页

首页不要做复杂 landing page。

建议改成一个轻量文档入口页：

- 顶部一句简短介绍
- 最近文档列表
- 每日英语入口
- 学习文档入口
- 文档站相关入口

可以用轻量分组，但不要把页面堆成一堆大卡片。

### 文章页

文章页优先提升阅读体验：

- 正文行高更舒服
- 标题间距更清楚
- H2 / H3 有轻微层次
- 链接颜色更柔和
- 代码块边框和背景更干净
- 引用块适合中文阅读

### 侧边栏

侧边栏要更清爽：

- 当前项高亮更明显但不要刺眼
- 分组标题稍微弱化
- 列表间距舒服一点
- 移动端不要拥挤

## 实现范围

优先只改这些文件：

```text
docs/.vitepress/theme/style.css
docs/.vitepress/config.ts
docs/index.md
```

如果需要首页更好看，可以增加一个自定义 Vue 组件，但第一版不建议复杂化。

第一版尽量不要引入新的 UI 库。

## 具体改动建议

### 1. 覆盖 VitePress 主题变量

在 `docs/.vitepress/theme/style.css` 里覆盖：

- `--vp-c-brand-1`
- `--vp-c-brand-2`
- `--vp-c-brand-3`
- `--vp-c-brand-soft`
- `--vp-c-bg`
- `--vp-c-bg-soft`
- `--vp-c-text-1`
- `--vp-c-text-2`
- `--vp-font-family-base`

目标是让站点整体从默认蓝紫感变成柔和青绿色系。

### 2. 优化中文排版

建议：

- 正文最大宽度保持 VitePress 默认或略微放宽
- 中文行高 1.85 左右
- 段落间距略增
- H2 上边距更大，下边距适中
- 避免负字距
- 不要用 viewport 缩放字体

### 3. 首页轻量重做

首页可以改成：

```md
# lshbosheth 文档

这里放学习计划、技术英语、项目记录和一些长期可查的内容。

## 常用入口

- 每日英语
- Go 学习启动计划
- Markdown 文档站方案

## 最近文档

- ...
```

也可以用少量 HTML class 做轻量布局，但不要做成营销首页。

### 4. 统一组件气质

已有 `Pronounce` 发音按钮的设计可以保留，但颜色要跟新主题统一。

重点：

- 按钮不要过亮
- hover 有轻微反馈
- 播放状态清楚
- 不要让按钮抢正文注意力

## 不要做

- 不要换掉 VitePress
- 不要引入大型 UI 框架
- 不要做营销首页
- 不要加大面积插画、装饰球、渐变背景
- 不要把页面做成卡片堆卡片
- 不要为了“小清新”牺牲阅读效率
- 不要改动 TTS 生成逻辑，除非明确需要

## 验收标准

完成后至少检查：

1. 首页是否比原来更有质感
2. 文章页是否更适合中文长期阅读
3. 每日英语页面的发音按钮是否仍正常
4. 桌面端和手机端是否都不挤
5. 暗色模式是否没有明显翻车
6. `npm run docs:build` 是否通过
7. 不出现大面积花哨渐变或营销风

## 给千问的任务提示词

你要优化一个 VitePress 文档站的视觉样式。

项目目录是 `docs-preview`，主要文件是：

```text
docs/.vitepress/theme/style.css
docs/.vitepress/config.ts
docs/index.md
```

目标是把默认 VitePress 样式升级为清爽、轻盈、适合中文阅读的小清新文档站风格。

请保持技术文档属性，不要做营销页，不要引入大型 UI 库，不要大面积渐变，不要堆卡片。

优先通过 CSS 变量和少量页面结构优化完成：

- 柔和青绿色品牌色
- 清爽白底
- 更舒服的中文行高和标题间距
- 更自然的侧边栏高亮
- 首页更像个人文档入口
- 保留已有 `Pronounce` 发音按钮功能

完成后运行：

```bash
npm run docs:build
```

如果构建失败，先修构建问题。
