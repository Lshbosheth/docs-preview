# 三、各科具体执行方法

# 3.1 英语单词执行方法

## A. 复习旧单词 300 个

### 时间控制

- 总时长：45 分钟
- 每 100 个单词：约 15 分钟
- 熟悉词：立即划过
- 模糊词：停留几秒
- 完全不会词：加入当天重点词清单

### 三类标记

```text
✅ 熟悉：看到后能快速反应常见义
△ 模糊：大概认识，但不能快速确定含义
× 不会：完全想不起来或经常混淆
```

### 旧词复习完成标准

- [ ] 完成 300 个旧词
- [ ] 熟悉词没有反复停留
- [ ] 标出模糊词
- [ ] 标出不会词
- [ ] 当天重点词不超过 30 个

---

## B. 学习新单词 150 个

### 第一遍重点

每个新单词优先处理：

1. 拼写和基本读音
2. 最常见的 1—2 个含义
3. 考研阅读中的常见义
4. 熟词僻义
5. 容易混淆的形近词

### 第一遍暂时不做

- 不给每个词抄很多遍
- 不背全部例句
- 不要求一次记住所有词义
- 不在单个词上停留几分钟
- 不因为少数难词拖延专业课

### 新词完成标准

- [ ] 接触完 150 个新词
- [ ] 能认出其中大部分单词
- [ ] 标记最难的 20—30 个
- [ ] 晚上再次回看难词
- [ ] 第二天进入旧词复习循环

# 3.2 英语阅读执行方法

## 每篇阅读流程

### 第一步：限时做题

- 不查单词
- 不看解析
- 不暂停计时
- 标出犹豫题
- 尽量写下选择依据

### 第二步：核对答案

每道错题回答：

1. 正确答案对应原文哪一句？
2. 自己为什么选错？
3. 错误选项用了什么干扰方式？
4. 是词汇、句子、逻辑还是粗心问题？
5. 下次怎样避免？

### 第三步：错因分类

```text
V：词汇不认识或熟词僻义不熟
S：长难句结构没有看懂
L：文章逻辑或段落关系没有理清
Q：题干理解错误
O：被干扰选项带偏
C：粗心、看漏、定位错误
T：时间紧张导致判断失误
```

### 第四步：简要复盘

每篇只记录：

- 文章主旨
- 错题编号
- 错因
- 2—5 个重点单词
- 1—2 个关键长难句
- 一个最需要改进的问题

### 阅读完成标准

- [ ] 做完两篇
- [ ] 对完答案
- [ ] 找到错题原文依据
- [ ] 标记错因
- [ ] 简要处理重点词和长难句
- [ ] 总时长没有超过计划太多

# 3.3 681 马原执行方法

## 每个知识点的标准学习流程

### 第一步：先确定问题

把教材内容改成一个问题，例如：

- 什么是物质？
- 物质和意识是什么关系？
- 实践有哪些基本特征？
- 为什么说社会生活在本质上是实践的？
- 社会基本矛盾包括什么？
- 商品二因素与劳动二重性是什么关系？

### 第二步：看清结构

识别：

- 总述句
- 一级分点
- 二级解释
- 关键词
- 逻辑连接词
- 方法论意义
- 现实意义

### 第三步：压缩成框架

示例：

```markdown
题目：

一、概念或总述
二、主要内容
1. 分点一
2. 分点二
3. 分点三
三、相互关系
四、方法论或现实意义
```

### 第四步：闭书复述

- 第一次复述：允许卡顿
- 对照教材纠错
- 第二次复述：说出完整框架
- 第三次复述：补充关键词和解释

### 第五步：当日验收

当天至少完成：

- 说出所学标题
- 抽背 3—5 个知识点
- 写 2 个答题框架
- 标记 3 个薄弱知识点

---

## 马原内容分级

### A 级：尽量准确背诵

- 概念定义
- 基本原理
- 重要关系
- 主要特征
- 基本内容
- 分点明确的简答题
- 教材总结性表述

### B 级：掌握框架并能展开

- 理论形成过程
- 原因、作用和意义
- 较长论证
- 历史发展过程
- 原理的具体解释

### C 级：理解即可

- 案例
- 过渡句
- 重复解释
- 一般性材料
- 注释和非核心引文

```markdown
题目：

一、含义或总述

2. 分点二
3. 分点三
三、具体解释
四、实践要求或现实意义
```

每个分点只先记：

1. 看题目口头说框架

# 九、没有完成时的补进度规则

## 规则一：第二天不能盲目翻倍

例如当天少背 6 页，第二天不要直接变成原计划加 6 页并全部硬背。

正确做法：

- 第二天最多增加原计划的 20%—25%
- 剩余内容放到最近的复习日
- 优先补核心定义和基本原理
- 案例、过渡内容暂时放后

---

## 规则二：英语阅读不积压超过一天

当天少做一篇：

- 第二天可以补一篇
- 第二天总量最多 3 篇
- 不连续多天积压
- 若连续积压，优先保证每天 2 篇，不再追补过早欠下的全部篇目

---

## 规则三：马原和 881 优先级高于形式化笔记

时间不足时，先保证：

1. 理解
2. 背诵
3. 闭书复述
4. 抽背

可以减少：

- 抄写
- 美化笔记
- 重新排版
- 大量摘录

---

## 规则四：复习日既复习也补缺

复习日最多拿出三分之一时间补进度，其余时间仍要复习。

否则复习日会变成普通学习日，前面内容得不到巩固。

# 十四、执行中的注意事项

1. **不要为了完成页码完全放弃复述。**  
   只看完 14 页但一句也说不出来，不算真正完成。

2. **不要在单词上消耗整个上午。**  
   单词任务到时间就停止，把时间留给专业课。

3. **不要把英语阅读做成全文翻译。**  
   重点是做题、定位、错因和关键句。

4. **不要过度美化笔记。**  
   笔记的作用是帮助回忆和答题，不是制作作品。

5. **不要连续多天积压。**  
   出现欠缺后，优先保住当天任务，再少量补旧任务。

6. **不要因为一天失败就推翻整个计划。**  
   第二天从固定时间重新开始。

7. **第一轮允许不完美。**  
   目标是建立全书框架，为第二轮精背打基础。

8. **每天必须有闭书输出。**  
   只有闭书回忆，才能判断自己是否真正掌握。

9. **回顾优先于重复阅读。**  
   先想，再看；先答，再核对。

10. **保证睡眠和正常吃饭。**  
    长期记忆依赖稳定状态，不靠连续熬夜硬撑。
