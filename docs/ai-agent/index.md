# AI Agent 每日一课

每天一篇短 Markdown，从基础概念开始，把 AI Agent 相关的核心知识慢慢整理成能复习、能解释、能落到工程里的笔记。

这个系列优先关注不容易过期的东西：Agent 和普通 Chatbot 的区别、工具调用、上下文、记忆、RAG、工作流、权限、评估、成本和可观测性。

后续每日文章会按日期自动追加到侧边栏。

## 今年学到什么程度算会了

每日一课负责持续铺开地图，[AI Agent 年度学习检查表](/ai-agent/checklist)负责验收。它不按“看过多少篇”计数，而按三个层次判断：能解释、能实现、能排障。

新框架和新名词仍会继续出现，但检索、状态、工具、编排、评估、安全与可靠性这些主干不会因为换了产品名就失效。
