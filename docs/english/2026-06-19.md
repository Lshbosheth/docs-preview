# 技术英语 10 分钟 - 2026-06-19

## 今日目标

读懂 <Pronounce text="failed to load module script" />、<Pronounce text="expected a JavaScript module script" /> 和 <Pronounce text="strict MIME type checking" /> 这类前端部署报错。

来源类型：<Pronounce text="error message and browser console output" />

## 原文

来源主题：<Pronounce text="browser module script loading error" />

<Pronounce text="Failed to load module script." />

<Pronounce text="Expected a JavaScript module script but the server responded with a MIME type of text/html." />

<Pronounce text="Strict MIME type checking is enforced for module scripts." />

参考场景：前端项目部署后，浏览器尝试加载打包产物，但服务器返回了 HTML 页面而不是 JavaScript 文件。

## 人话意思

第一句说：浏览器没能加载这个 <Pronounce text="module script" />。

第二句是关键：浏览器本来期待拿到 <Pronounce text="a JavaScript module script" />，但服务器返回的类型是 <Pronounce text="text/html" />。这通常意味着资源路径错了、构建产物没上传、路由兜底把请求转到了首页，或者静态文件服务配置不对。

第三句说：对 <Pronounce text="module scripts" />，浏览器会严格检查 <Pronounce text="MIME type" />。别看到一大串就慌，笨蛋，这类报错的核心经常只有一句：你要的是 JS，服务器给了 HTML。

## 关键词

- <Pronounce text="failed to load" />: 加载失败
- <Pronounce text="module script" />: 模块脚本，通常是带 <Pronounce text="type module" /> 的 JavaScript 文件
- <Pronounce text="expected" />: 期望，本来应该得到
- <Pronounce text="responded with" />: 返回了，用某种内容响应
- <Pronounce text="MIME type" />: 内容类型，告诉浏览器这个响应是什么格式
- <Pronounce text="text/html" />: HTML 文档类型
- <Pronounce text="strict checking" />: 严格检查
- <Pronounce text="is enforced" />: 被强制执行

## 句子拆解

<Pronounce text="Failed to load module script." />

这句省略了主语，完整理解可以补成：浏览器 <Pronounce text="failed to load" /> 这个 <Pronounce text="module script" />。

核心结构很短：

<Pronounce text="Failed to load" />

对象是：

<Pronounce text="module script" />

<Pronounce text="Expected a JavaScript module script but the server responded with a MIME type of text/html." />

前半句是浏览器期待的东西：

<Pronounce text="Expected a JavaScript module script" />

后半句是服务器实际返回的东西：

<Pronounce text="but the server responded with a MIME type of text/html" />

这里的 <Pronounce text="but" /> 很重要，它把“期望”和“实际结果”对起来。技术报错里看到这种结构，先找两边不一致的地方。

<Pronounce text="Strict MIME type checking is enforced for module scripts." />

主语是：

<Pronounce text="Strict MIME type checking" />

动作状态是：

<Pronounce text="is enforced" />

适用范围是：

<Pronounce text="for module scripts" />

这句不用翻得很硬，顺手理解成：浏览器会对模块脚本强制做内容类型检查。

## 今天记住一句

<Pronounce text="The server responded with a MIME type of text/html." />

以后定位前端部署问题时，看到 <Pronounce text="responded with" />，先按“服务器返回了……”理解。

<Pronounce text="The browser expected a JavaScript module script, but the server returned an HTML page." />

提示：<Pronounce text="expected" /> 是“期望”，<Pronounce text="returned an HTML page" /> 是“返回了一个 HTML 页面”。
