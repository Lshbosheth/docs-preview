# 技术英语 10 分钟 - 2026-06-08

## 今日目标

练会一句浏览器文档里很常见的表达：某个东西会把数据保存成某种格式。

## 原文

来源类型：<Pronounce text="MDN browser JavaScript" />

<Pronounce text="The browser stores localStorage data as strings." />

<Pronounce text="Use JSON to save an object, then parse it when you read it back." />

## 人话意思

今天这两句在说：浏览器里的本地存储并不是“想塞什么对象就塞什么对象”，它最后保存的是字符串。

所以如果你要存一个对象，常见做法是先转成 <Pronounce text="JSON" />，读出来以后再解析回对象。

## 关键词

- <Pronounce text="browser" />: 浏览器
- <Pronounce text="stores" />: 保存，存储
- <Pronounce text="localStorage data" />: 本地存储里的数据
- <Pronounce text="as strings" />: 以字符串的形式
- <Pronounce text="save an object" />: 保存一个对象
- <Pronounce text="parse it" />: 解析它
- <Pronounce text="read it back" />: 把它读回来

## 句子拆解

<Pronounce text="The browser stores localStorage data as strings." />

主语是 <Pronounce text="The browser" />。

动作是 <Pronounce text="stores" />，意思是“保存”。

保存的东西是 <Pronounce text="localStorage data" />。

最后的 <Pronounce text="as strings" /> 很关键，表示“以字符串的形式”。

所以这句不用绕：浏览器把 <Pronounce text="localStorage" /> 里的数据保存成字符串。

<Pronounce text="Use JSON to save an object, then parse it when you read it back." />

这句有两个动作：

<Pronounce text="Use JSON to save an object" />

先用 <Pronounce text="JSON" /> 保存对象。

<Pronounce text="then parse it when you read it back" />

然后读回来时再解析它。

这里的 <Pronounce text="when you read it back" /> 可以理解成“当你把它读回来时”。

## 今天记住一句

<Pronounce text="The browser stores localStorage data as strings." />

以后看到 <Pronounce text="as strings" />，先按“以字符串形式”理解，别把它翻复杂。
