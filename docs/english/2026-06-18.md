## 人话意思

第一句说：<Pronounce text="streamText" /> 会从语言模型那里“流式输出文本生成结果”，不是等整段生成完才一次性给你。

第二句说：这种函数适合交互场景，比如 <Pronounce text="chat bots" /> 和实时应用。你做聊天 UI、边生成边展示时，就会经常看到这类表达。

第三句说：更高级的 LLM 能力，比如 <Pronounce text="tool calling" /> 和 <Pronounce text="structured data generation" />，本质上是建立在文本生成能力之上的。别被长词吓住，笨蛋，这句是在讲“底座能力”和“上层能力”的关系。

## 句子拆解

<Pronounce text="Streams text generations from a language model." />

这句省略了主语，文档标题或函数名已经告诉你主语是 <Pronounce text="streamText" />。

核心动作是：

<Pronounce text="Streams text generations" />

来源是：

<Pronounce text="from a language model" />

整句可以理解成：从语言模型那里流式传出文本生成结果。

<Pronounce text="You can use the streamText function for interactive use cases such as chat bots and other real-time applications." />

主干是：

<Pronounce text="You can use the streamText function" />

用途是：

<Pronounce text="for interactive use cases" />

后面的例子是：

<Pronounce text="such as chat bots and other real-time applications" />

<Pronounce text="such as" /> 就是“比如”，技术文档里特别常见，用来补几个典型场景。

<Pronounce text="Advanced LLM features such as tool calling and structured data generation are built on top of text generation." />

主语是一整块：

<Pronounce text="Advanced LLM features such as tool calling and structured data generation" />

判断部分是：

<Pronounce text="are built on top of text generation" />

<Pronounce text="built on top of" /> 不要直译成“建在顶部”，在技术语境里更自然的是“基于……构建”。

## 今天记住一句

<Pronounce text="This feature is built on top of text generation." />

以后描述某个上层能力基于底层能力实现，就可以套这个句型：

<Pronounce text="This feature is built on top of..." />
