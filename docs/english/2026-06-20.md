# 技术英语 10 分钟 - 2026-06-20

## 今日目标

用 10 分钟复习三个技术文档里很常见的表达：<Pronounce text="find problems" />、<Pronounce text="built on top of" /> 和 <Pronounce text="responded with" />。

来源类型：<Pronounce text="light review" />

## 原文

来源主题：<Pronounce text="frontend and AI tooling review" />

<Pronounce text="The tool finds problems without executing the code." />

<Pronounce text="This feature is built on top of text generation." />

<Pronounce text="The server responded with a MIME type of text/html." />

参考场景：公开前端工具文档、AI 工具文档和浏览器错误信息里的常见表达。

## 人话意思

第一句说：这个工具不用真正运行代码，也能发现问题。它适合描述 <Pronounce text="static analysis" />、<Pronounce text="linting" /> 或代码检查工具。

第二句说：这个功能是基于文本生成能力构建出来的。技术文档里看到 <Pronounce text="built on top of" />，不用硬翻成“建在上面”，顺手理解成“基于……实现”就行。

第三句说：服务器返回的内容类型是 <Pronounce text="text/html" />。这类句子经常出现在前端部署报错里，核心是“浏览器想要一种资源，但服务器给了另一种”。

## 关键词

- <Pronounce text="find problems" />: 发现问题
- <Pronounce text="without executing the code" />: 不执行代码
- <Pronounce text="built on top of" />: 基于……构建
- <Pronounce text="feature" />: 功能
- <Pronounce text="text generation" />: 文本生成
- <Pronounce text="responded with" />: 返回了，以某种内容响应
- <Pronounce text="MIME type" />: 内容类型
- <Pronounce text="text/html" />: HTML 文档类型

## 句子拆解

<Pronounce text="The tool finds problems without executing the code." />

主语是：

<Pronounce text="The tool" />

动作是：

<Pronounce text="finds problems" />

方式或限制是：

<Pronounce text="without executing the code" />

这里的 <Pronounce text="without" /> 后面接 <Pronounce text="executing" />，意思是“不做某个动作”。技术文档里常见，比如“不运行代码”“不重新加载页面”“不改变原始数据”。

<Pronounce text="This feature is built on top of text generation." />

主语是：

<Pronounce text="This feature" />

核心判断是：

<Pronounce text="is built on top of" />

基础能力是：

<Pronounce text="text generation" />

整句就是：这个功能是基于文本生成构建的。以后描述 AI 工具的上层能力，比如工具调用、结构化输出、聊天 UI，都可以套这个结构。

<Pronounce text="The server responded with a MIME type of text/html." />

主语是：

<Pronounce text="The server" />

动作是：

<Pronounce text="responded with" />

返回的内容是：

<Pronounce text="a MIME type of text/html" />

看到 <Pronounce text="responded with" />，先按“服务器返回了……”理解。它通常在帮你定位“实际返回”和“期望返回”哪里不一致。

## 今天记住一句

<Pronounce text="This feature is built on top of text generation." />

这个句型很适合技术沟通：说某个高级功能是基于某个底层能力实现的。

可以换成：

<Pronounce text="This workflow is built on top of static analysis." />

<Pronounce text="This UI is built on top of streaming responses." />
