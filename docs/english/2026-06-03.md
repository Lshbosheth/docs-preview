# 技术英语 10 分钟 - 2026-06-03

## 今日目标

看懂开源 README 里常见的“安装、启动、构建”表达。

## 原文

来源：开源项目 README 常见用法

<Pronounce text="Install the dependencies, then start the development server." />

<Pronounce text="When you are ready, build the project for production." />

<Pronounce text="The output files will be generated in the dist directory." />

## 人话意思

第一句是在说：先装依赖，再启动开发服务器。

第二句是在说：准备好了之后，把项目构建成生产环境版本。

第三句是在说：构建出来的文件会放到 `dist` 目录里。

## 关键词

- <Pronounce text="install the dependencies" />: 安装依赖
- <Pronounce text="start the development server" />: 启动开发服务器
- <Pronounce text="build the project" />: 构建项目
- <Pronounce text="for production" />: 用于生产环境
- <Pronounce text="output files" />: 输出文件
- <Pronounce text="dist directory" />: `dist` 目录，通常放构建产物

## 句子拆解

<Pronounce text="Install the dependencies, then start the development server." />

这句是两个命令动作连在一起：

<Pronounce text="Install the dependencies" /> 是第一步。

<Pronounce text="then start the development server" /> 是第二步。

README 里经常省略主语，实际意思是“你需要做这些事”。

<Pronounce text="When you are ready, build the project for production." />

<Pronounce text="When you are ready" /> 表示“当你准备好时”。

<Pronounce text="build the project for production" /> 不是“盖项目”，而是“把项目打包成生产环境可用的版本”。

<Pronounce text="The output files will be generated in the dist directory." />

这里的 <Pronounce text="will be generated" /> 是被动语态，意思是“会被生成”。

技术文档里常用被动语态，因为重点不是“谁生成”，而是“文件会出现在哪里”。
