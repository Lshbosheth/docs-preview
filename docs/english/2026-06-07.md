# 技术英语 10 分钟 - 2026-06-07

## 今日目标

用一个很轻的部署句子，练会 `when ... finishes` 这种技术文档里常见的时间条件表达。

## 原文

来源：部署 / tooling 文档常见表达

<Pronounce text="The deployment is ready when the build finishes." />

## 人话意思

这句话是在说：构建完成之后，部署就准备好了。

周日不加量，今天只吃这一口。它常出现在 Vercel、CI、构建工具这类上下文里：先等某个步骤结束，再进入下一个状态。

## 关键词

- <Pronounce text="deployment" />: 部署，把项目发布到可访问环境
- <Pronounce text="is ready" />: 已准备好，可以用了
- <Pronounce text="when" />: 当……的时候
- <Pronounce text="build" />: 构建，把源码打包成可运行或可发布的产物
- <Pronounce text="finishes" />: 完成，结束

## 句子拆解

<Pronounce text="The deployment is ready when the build finishes." />

主句是：

<Pronounce text="The deployment is ready" />

意思是“部署已经准备好”。

后半句是：

<Pronounce text="when the build finishes" />

它说明时间条件：什么时候 ready？当 build 完成的时候。

这里的 <Pronounce text="when" /> 不一定要翻成很硬的“当……时”，读技术文档时可以顺手理解成“等……之后”。

## 今天记住一句

<Pronounce text="The deployment is ready when the build finishes." />

以后看到 <Pronounce text="when something finishes" />，先按“等某个步骤完成后”理解。

## 30 秒小练习

把下面这句翻成中文：

<Pronounce text="The preview is ready when the server starts." />

提示：<Pronounce text="preview" /> 是预览页面，<Pronounce text="server starts" /> 是服务启动。
