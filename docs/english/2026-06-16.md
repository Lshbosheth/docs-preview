## 原文

来源主题：<Pronounce text="React memo and re-rendering" />

<Pronounce text="React normally re-renders a component whenever its parent re-renders." />

<Pronounce text="With memo, you can create a component that React will not re-render when its parent re-renders so long as its new props are the same as the old props." />

<Pronounce text="Memoization is a performance optimization, not a guarantee." />

参考：<Pronounce text="React documentation" />，<Pronounce text="memo" />。

## 人话意思

第一句说：在正常情况下，只要父组件重新渲染，子组件也可能跟着重新渲染。

第二句说：用 <Pronounce text="memo" /> 包一下组件后，如果新旧 <Pronounce text="props" /> 没变，React 通常可以跳过这次子组件渲染。

第三句很关键：<Pronounce text="memoization" /> 是性能优化，不是绝对保证。别把它理解成“用了就永远不会重新渲染”，笨蛋，这种坑 React 文档都提前替你写脸上了。

## 关键词

- <Pronounce text="re-render" />: 重新渲染，组件再次执行并生成界面结果
- <Pronounce text="parent re-renders" />: 父组件重新渲染
- <Pronounce text="memoized component" />: 被记忆化处理过的组件
- <Pronounce text="props have not changed" />: props 没有变化
- <Pronounce text="the same as" />: 和……一样
- <Pronounce text="performance optimization" />: 性能优化
- <Pronounce text="not a guarantee" />: 不是保证，不是绝对承诺

## 句子拆解

<Pronounce text="React normally re-renders a component whenever its parent re-renders." />

主语是：

<Pronounce text="React" />

动作是：

<Pronounce text="re-renders a component" />

后半句：

<Pronounce text="whenever its parent re-renders" />

这里的 <Pronounce text="whenever" /> 可以先按“每当……”理解。

整句就是：每当父组件重新渲染时，React 通常也会重新渲染这个组件。

<Pronounce text="With memo, you can create a component that React will not re-render when its parent re-renders so long as its new props are the same as the old props." />

开头的 <Pronounce text="With memo" /> 表示“借助 memo / 使用 memo”。

核心句子是：

<Pronounce text="you can create a component" />

后面的 <Pronounce text="that React will not re-render" /> 是在修饰这个组件：React 不会重新渲染它。

条件是：

<Pronounce text="so long as its new props are the same as the old props" />

<Pronounce text="so long as" /> 在这里等于 <Pronounce text="as long as" />，意思是“只要……”。

<Pronounce text="Memoization is a performance optimization, not a guarantee." />

主语是 <Pronounce text="Memoization" />。

判断句结构是：

<Pronounce text="is a performance optimization" />

后面的 <Pronounce text="not a guarantee" /> 是补充边界：它只是优化手段，不是行为承诺。
