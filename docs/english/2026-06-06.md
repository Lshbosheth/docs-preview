## 人话意思

这几句都很像真实文档或报错里的表达：谁做了什么、把什么传给谁、检查什么是否正确。

## 关键词

- <Pronounce text="return a value" />: 返回一个值
- <Pronounce text="pass props" />: 传递 props
- <Pronounce text="process the input" />: 处理输入
- <Pronounce text="return a response" />: 返回响应

- <Pronounce text="is correct" />: 是正确的

## 句子拆解

<Pronounce text="A function returns a value." />

主语是 <Pronounce text="A function" />，动作是 <Pronounce text="returns" />，对象是 <Pronounce text="a value" />。

这就是技术文档里最常见的短句骨架：某个东西做某件事。

<Pronounce text="A parent component passes props to a child component." />

这里的核心动作是 <Pronounce text="passes" />。

<Pronounce text="to a child component" /> 说明 props 被传给谁。

<Pronounce text="The model processes the input and returns a response." />

一句话里有两个动作：<Pronounce text="processes the input" /> 和 <Pronounce text="returns a response" />。

看到 <Pronounce text="and" />，先找它连接的是两个词、两个短语，还是两个动作。

<Pronounce text="Check that the import path is correct." />

<Pronounce text="Check that" /> 后面接要检查的内容。

这里要检查的是：<Pronounce text="the import path is correct" />。

## 今天记住一句

<Pronounce text="Check that the import path is correct." />

以后看到 `check that ...`，先按“检查某件事是否成立”理解。
