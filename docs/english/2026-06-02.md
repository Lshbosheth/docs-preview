# 技术英语 10 分钟 - 2026-06-02

## 今日目标

看懂前端文档里怎么说“组件通过属性传信息”。

## 原文

来源：官方前端框架文档（https://react.dev/learn/passing-props-to-a-component）

<Pronounce text="React components use props to communicate with each other." />

<Pronounce text="Every parent component can pass some information to its child components by giving them props." />

## 人话意思

第一句是在说：组件之间不是直接乱伸手拿数据，而是用属性来沟通。

第二句是在说：父组件可以把一些信息交给子组件，方式就是传属性。

## 关键词

- <Pronounce text="component" />: 组件，页面里一块可复用的界面或逻辑
- <Pronounce text="props" />: 属性，父组件传给子组件的数据
- <Pronounce text="communicate with each other" />: 互相沟通
- <Pronounce text="parent component" />: 父组件，负责往下传信息的组件
- <Pronounce text="child component" />: 子组件，接收信息并渲染内容的组件
- <Pronounce text="pass some information" />: 传递一些信息

## 句子拆解

<Pronounce text="React components use props" />

主语是 <Pronounce text="React components" />，动作是 <Pronounce text="use" />，对象是 <Pronounce text="props" />。
这类句子在技术文档里很常见：先说“谁”，再说“用什么”。

<Pronounce text="to communicate with each other" />

这里的 <Pronounce text="to" /> 表示目的。
整段的意思是：组件使用属性，是为了彼此传递信息。

<Pronounce text="Every parent component can pass some information" />

<Pronounce text="Every" /> 不用翻得很死，技术文档里常常就是“每个 / 任意一个”。
<Pronounce text="can pass" /> 是“可以传递”，不是“会通过考试”的那个意思。

<Pronounce text="to its child components by giving them props" />

<Pronounce text="to its child components" /> 说明信息传给谁。
<Pronounce text="by giving them props" /> 说明方式：通过给它们属性。
