## 今日目标

用 10 分钟练会技术文档里描述函数返回值的句子，重点看懂 <Pronounce text="ends function execution" /> 和 <Pronounce text="returned to the function caller" />。

来源类型：<Pronounce text="MDN Web Docs, browser and JavaScript" />

## 原文

来源主题：公开 <Pronounce text="MDN Web Docs" /> 里的 <Pronounce text="JavaScript return statement" /> 说明。

<Pronounce text="The return statement ends function execution and specifies a value to be returned to the function caller." />

参考链接：https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/return

## 人话意思

这句话是在说：<Pronounce text="return" /> 会让函数停止继续执行，并指定一个值，把这个值交回给调用这个函数的地方。

看到 <Pronounce text="ends function execution" />，不要硬翻成很绕的“结束函数执行过程”，顺手理解成“函数到这里停下”。

看到 <Pronounce text="returned to the function caller" />，重点是“返回给调用方”。调用方可以是另一行代码、另一个函数，或者你在控制台里执行的那次调用。

## 关键词

- <Pronounce text="return statement" />: 返回语句
- <Pronounce text="ends" />: 结束，停止
- <Pronounce text="function execution" />: 函数执行
- <Pronounce text="specifies a value" />: 指定一个值
- <Pronounce text="returned to" />: 返回给
- <Pronounce text="function caller" />: 函数调用方

## 句子拆解

<Pronounce text="The return statement ends function execution and specifies a value to be returned to the function caller." />

主语是：

<Pronounce text="The return statement" />

第一个动作是：

<Pronounce text="ends function execution" />

第二个动作是：

<Pronounce text="specifies a value" />

后面这段说明这个值要去哪里：

<Pronounce text="to be returned to the function caller" />

整句骨架可以压成：

<Pronounce text="A ends B and specifies C." />

意思是：某个东西结束 B，并指定 C。

技术文档里这种结构很常见，因为它喜欢一次讲清楚“动作”和“结果”：

<Pronounce text="The command stops the server and prints a message." />

<Pronounce text="The option disables caching and returns fresh data." />
