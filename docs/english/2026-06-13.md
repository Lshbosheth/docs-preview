## 原文

来源：本周技术英语里的通用文档表达复盘。

<Pronounce text="The command deploys your local project to a remote environment." />

<Pronounce text="Enable source maps to trace the stack back to the original source file." />

<Pronounce text="If the build succeeds, the tool returns a production URL." />

## 人话意思

第一句说：这个命令会把本地项目部署到远程环境。

第二句说：启用 <Pronounce text="source maps" />，就能把调用栈追溯回原始源码文件。

第三句说：如果构建成功，工具会返回一个生产环境地址。

这三句放在一起，其实就是一条很常见的前端工作流：运行命令、部署项目、构建成功后拿到地址；如果报错，就用源映射回到源码定位问题。

## 关键词

- <Pronounce text="command" />: 命令，终端里运行的一行指令
- <Pronounce text="deploys" />: 部署，把项目发布到某个环境
- <Pronounce text="local project" />: 本地项目
- <Pronounce text="remote environment" />: 远程环境，不在本机上的运行环境
- <Pronounce text="enable" />: 启用
- <Pronounce text="source maps" />: 源映射，用来把压缩后的代码对应回原始源码
- <Pronounce text="trace the stack back to" />: 把调用栈追溯回
- <Pronounce text="build succeeds" />: 构建成功
- <Pronounce text="production URL" />: 生产环境地址

## 句子拆解

<Pronounce text="The command deploys your local project to a remote environment." />

主语是 <Pronounce text="The command" />。

动作是 <Pronounce text="deploys" />。

被部署的对象是 <Pronounce text="your local project" />。

方向是 <Pronounce text="to a remote environment" />，表示“到远程环境”。

这类句子很好读：先找动作，再看“把什么放到哪里”。

<Pronounce text="Enable source maps to trace the stack back to the original source file." />

这是命令句，省略了主语 <Pronounce text="you" />。

动作是 <Pronounce text="Enable source maps" />。

目的在后面：<Pronounce text="to trace the stack back to the original source file" />。

看到 <Pronounce text="to" /> 后面接动词时，很多时候可以先按“为了……”理解。

<Pronounce text="If the build succeeds, the tool returns a production URL." />

前半句 <Pronounce text="If the build succeeds" /> 是条件。

后半句 <Pronounce text="the tool returns a production URL" /> 是结果。

技术文档里这种结构很常见：如果某一步成功，工具就会返回某个结果。

## 今天记住一句

<Pronounce text="If the build succeeds, the tool returns a production URL." />

以后看到 <Pronounce text="If something succeeds, something returns a result" />，先按“如果某一步成功，工具会返回结果”理解。
