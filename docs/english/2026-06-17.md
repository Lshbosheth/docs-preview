来源类型：<Pronounce text="GitHub README and open source docs" />

## 原文

来源主题：<Pronounce text="ESLint and static analysis" />

<Pronounce text="ESLint statically analyzes your code to quickly find problems." />

<Pronounce text="Most problems ESLint finds can be automatically fixed." />

<Pronounce text="Static analysis checks code without executing it." />

参考：<Pronounce text="ESLint open source documentation" />，<Pronounce text="README and getting started guide" />。

## 人话意思

第一句说：<Pronounce text="ESLint" /> 会做静态分析，也就是不真的运行代码，先从代码文本本身找问题。

第二句说：很多被 <Pronounce text="ESLint" /> 找到的问题可以自动修复，比如格式、简单规则和一部分明显写法。

第三句把 <Pronounce text="static analysis" /> 解释清楚：它检查代码，但不执行代码。别看到 <Pronounce text="analysis" /> 就脑袋发胀，笨蛋，这里就是“先扫一遍代码”的意思。

## 关键词

- <Pronounce text="statically analyzes" />: 静态分析，不运行代码也能检查问题
- <Pronounce text="find problems" />: 发现问题，技术文档里常指找 bug、风格问题或潜在风险
- <Pronounce text="automatically fixed" />: 被自动修复
- <Pronounce text="static analysis" />: 静态分析
- <Pronounce text="checks code" />: 检查代码
- <Pronounce text="without executing it" />: 不执行它
- <Pronounce text="quickly" />: 快速地

## 句子拆解

<Pronounce text="ESLint statically analyzes your code to quickly find problems." />

主语是：

<Pronounce text="ESLint" />

动作是：

<Pronounce text="statically analyzes your code" />

后面的目的：

<Pronounce text="to quickly find problems" />

这里的 <Pronounce text="to" /> 后面接动词，先按“为了……”理解。

整句就是：ESLint 静态分析你的代码，为了快速发现问题。

<Pronounce text="Most problems ESLint finds can be automatically fixed." />

主语不是单独的 <Pronounce text="problems" />，而是这一整块：

<Pronounce text="Most problems ESLint finds" />

意思是“ESLint 找到的大多数问题”。

后半句：

<Pronounce text="can be automatically fixed" />

这是被动结构，意思是“可以被自动修复”。

<Pronounce text="Static analysis checks code without executing it." />

主语是：

<Pronounce text="Static analysis" />

动作是：

<Pronounce text="checks code" />

方式或限制是：

<Pronounce text="without executing it" />

这里的 <Pronounce text="without" /> 后面接 <Pronounce text="executing" />，意思是“不做某个动作”。技术文档里很常见。
