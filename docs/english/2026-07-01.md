## 1. 常用单词

### simple

<Pronounce text="simple" />

```text
/ˈsɪm.pəl/
简单的
```

注意：后半段是轻轻的 `pəl`，不要读成很重的 “po”。

### stable

<Pronounce text="stable" />

```text
/ˈsteɪ.bəl/
稳定的
```

注意：开头是 <Pronounce text="stay" /> 的音，不是 “sta”。

### enough

<Pronounce text="enough" />

```text
/ɪˈnʌf/
足够的
```

注意：结尾是 `f` 音，不是 `g` 音。

### clear

<Pronounce text="clear" />

```text
/klɪr/
清楚的
```

注意：`cl` 要连起来，不要拆成 “ke-leer”。

## 2. 技术单词

### cache

<Pronounce text="cache" />

```text
/kæʃ/
缓存
```

注意：读起来像 “cash”，不是 <Pronounce text="catch" />。

### queue

<Pronounce text="queue" />

```text
/kjuː/
队列
```

注意：这个词看起来很长，但只读一个音，像字母 <Pronounce text="Q" />。

### schema

<Pronounce text="schema" />

```text
/ˈskiː.mə/
结构定义 / 数据模式
```

注意：技术语境里常读成 `SKEE-muh`，开头是 `ski` 的音。

### latency

<Pronounce text="latency" />

```text
/ˈleɪ.tən.si/
延迟
```

注意：开头是 <Pronounce text="lay" /> 的音，不要读成 “la-ten-cy”。

## 4. 今日重点跟读

<Pronounce text="We need a simple and stable memory system." />

```text
We need a simple and stable memory system.
我们需要一个简单且稳定的记忆系统。
```

节奏：

```text
We need / a simple and stable / memory system.
```

不要一口气糊过去。

先把 <Pronounce text="simple and stable" /> 读顺，再读完整句。
