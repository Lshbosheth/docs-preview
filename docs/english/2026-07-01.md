## 人话意思

这段 README 不是在讲安装步骤，而是在讲 Vite 的定位。

第一句说：Vite 是一个构建工具，它的目标是让现代 Web 项目的开发体验更快、更轻。

第二句把结构拆开：它主要有两块，一块是开发服务器，一块是构建命令。

第三句补一个关键卖点：开发服务器能提供很快的 HMR，也就是改完代码后页面快速更新。

## 关键词

- <Pronounce text="build tool" />: 构建工具，负责开发、打包、产物生成这类流程。
- <Pronounce text="aims to provide" />: 目标是提供。README 里很常见，用来说明项目目的。
- <Pronounce text="faster and leaner" />: 更快、更轻。<Pronounce text="leaner" /> 这里不是“瘦”，而是“不臃肿”。
- <Pronounce text="development experience" />: 开发体验，指启动、调试、刷新、构建等整体感受。
- <Pronounce text="modern web projects" />: 现代 Web 项目，通常指使用模块化、框架、构建工具链的前端项目。
- <Pronounce text="dev server" />: 开发服务器，本地开发时跑起来的服务。
- <Pronounce text="build command" />: 构建命令，用来生成生产环境产物。
- <Pronounce text="Hot Module Replacement" />: 热模块替换，常缩写为 <Pronounce text="H M R" />。

## 句子拆解

### 句子 1

<Pronounce text="Vite is a build tool that aims to provide a faster and leaner development experience for modern web projects." />

主干很简单：

```text
Vite is a build tool.
```

<Pronounce text="Vite is a build tool." />

后面这一长串是在修饰 <Pronounce text="build tool" />：

```text
that aims to provide a faster and leaner development experience
```

<Pronounce text="that aims to provide a faster and leaner development experience" />

最后的 <Pronounce text="for modern web projects" /> 说明服务对象：

```text
for modern web projects
```

所以读的时候别被长句吓到，先抓三块：

```text
Vite is a build tool / that aims to provide / a faster and leaner development experience.
```

<Pronounce text="Vite is a build tool that aims to provide a faster and leaner development experience." />

### 句子 2

<Pronounce text="It consists of two major parts: a dev server and a build command." />

这里的 <Pronounce text="consists of" /> 很常见，意思是“由什么组成”。

结构是：

```text
It consists of A and B.
```

<Pronounce text="It consists of A and B." />

你以后写技术文档也可以直接套：

<Pronounce text="The package consists of a client and a server." />

```text
The package consists of a client and a server.
这个包由一个客户端和一个服务端组成。
```

### 句子 3

<Pronounce text="The dev server provides fast Hot Module Replacement." />

这个句子是最标准的“谁提供什么”：

```text
The dev server / provides / fast Hot Module Replacement.
```

<Pronounce text="The dev server provides fast Hot Module Replacement." />

技术文档里 <Pronounce text="provide" /> 很高频。

它比 <Pronounce text="give" /> 更正式一点，常用来描述能力、功能、接口和服务。

## 今天记住一句

<Pronounce text="It consists of two major parts." />

```text
It consists of two major parts.
它由两个主要部分组成。
```

这个句子很适合描述工具、系统、模块和方案。

换几个技术语境：

<Pronounce text="The system consists of three services." />

```text
The system consists of three services.
这个系统由三个服务组成。
```

<Pronounce text="The feature consists of a form and a preview panel." />

```text
The feature consists of a form and a preview panel.
这个功能由一个表单和一个预览面板组成。
```
