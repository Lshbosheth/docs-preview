# 交付工作项模板

> 每一个可实施任务都用此模板，避免只写“实现某模块”而缺少验收、故障语义和回滚方案。

## 基本信息

```text
编号：P?-???
标题：
所属阶段：
负责人：
状态：待确认 / Ready / 进行中 / 阻塞 / 已验收
依赖：
目标版本或窗口：
```

## 用户结果

用一两句话说明完成后用户能感受到什么变化。不要只描述内部类名或接口。

## 范围

本工作项包含：

- （填写）

本工作项不包含：

- （填写）

## 契约和状态

```text
输入：
输出：
幂等键：
状态变化：
超时语义：
重试语义：
```

## 实施任务

- [ ] 数据结构或迁移
- [ ] 核心逻辑
- [ ] 配置与功能开关
- [ ] 脱敏日志、指标和告警
- [ ] 单元与集成测试
- [ ] 故障注入和兼容回归
- [ ] 文档与运维说明

## 验收用例

至少覆盖：

1. 正常路径。
2. 重复输入和并发输入。
3. 超时、断连和部分成功。
4. 重启后的恢复路径。
5. 敏感信息和日志脱敏。
6. 功能关闭或回滚后的行为。

## 发布和回滚

```text
启用方式：
灰度范围：
观察指标：
停止条件：
回滚步骤：
数据兼容性：
```

## 完成证据

```text
测试报告：
真实链路记录：
指标或日志查询：
已知限制：
遗留工作项：
验收人和时间：
```
