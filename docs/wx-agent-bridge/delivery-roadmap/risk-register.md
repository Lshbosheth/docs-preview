# 主线风险台账

> 风险台账记录“可能让主线失败的条件”，不是普通 bug 列表。每次阶段验收、灰度扩大和正式切换前都要复查。

| ID | 风险 | 早期信号 | 主要缓解 | 停止 / 回滚条件 |
| --- | --- | --- | --- | --- |
| R01 | 同一微信账号存在两个 iLink 消费者 | 同一 `messageId` 被不同实例接收或出现双回复 | 单消费者租约；启动前探测；发送端幂等 | 发现任一双回复立即停止新实例发送 |
| R02 | iLink token、协议或 SDK 行为变化 | 鉴权失败上升、游标反复、消息格式未知 | 适配器隔离；契约测试；令牌刷新告警 | 持续无法拉取或发送则退回当前链路 |
| R03 | app-server 协议或 Codex 事件格式漂移 | 未识别事件、终态缺失、附件解析失败 | 协议版本探测；未知事件保留和告警；兼容样本回放 | 出现空响应、误判成功或附件丢失 |
| R04 | 长 turn 或旧 thread 造成会话卡死 | turn 时长异常、队列持续增长、恢复反复失败 | 分级超时；安全中断；新 thread 降级；队列上限 | 会话无法清空或影响其他会话 |
| R05 | 重试重放了有副作用工具 | 相同工具调用 ID 或外部变更重复发生 | 记录副作用边界；仅安全阶段重试；幂等键 | 检测到任一重复副作用立即关闭自动重试 |
| R06 | 记忆污染导致长期错误上下文 | 低置信候选被反复注入、用户频繁纠正 | 来源与置信度；候选态；冲突检测；可删除 | 无法解释来源或无法关闭注入 |
| R07 | 私密上下文泄漏给日志、模型或 Agent | 日志出现令牌/原文，审计缺目标或目的 | 默认最小披露；脱敏；高敏确认；审计 | 任何密钥或未经允许的高敏信息外发 |
| R08 | 生图完成但回复层追加空消息 | 已发送附件后仍走文本兜底 | `responseArtifacts` 作为回复终态；端到端回归 | 真实会话复现一次即阻止放量 |
| R09 | 计划内或异常重启后错误报“已恢复” | 健康检查未通过就通知用户 | 恢复屏障；主动探测拉取、Agent 和发送路径 | 健康检查失败或通知早于恢复完成 |
| R10 | Windows 进程和文件句柄导致重启不彻底 | 旧 PID 存活、端口占用、日志句柄未释放 | 精确 PID/端口校验；单实例锁；重启后身份确认 | 新旧实例并存或端口归属不明 |
| R11 | Admin Web 成为主链路单点 | 后台故障同时导致微信处理失败 | 控制面与数据面隔离；后台只读优先 | 后台异常影响收发时关闭后台相关功能 |
| R12 | 数据迁移不可逆或新旧版本不兼容 | 回滚后读失败、状态字段丢失 | 向后兼容迁移；先扩展后收缩；备份恢复演练 | 未验证恢复前禁止正式切换 |
| R13 | 轻量错误回复 AI 编造运行状态 | 已失败任务被描述为“还在处理” | 只传结构化脱敏状态；模板约束；本地兜底 | 发生一次错误状态承诺即关闭 AI 错误改写 |
| R14 | 队列反馈过多造成用户轰炸 | 同一入站消息收到多条排队/兜底提示 | 每消息一次兜底；状态变化去重；会话级节流 | 超过约定回复次数立即关闭中间提示 |

## 复查节奏

- 每期进入开发前：确认新增风险和风险责任人。
- 每期验收前：附上高风险项的测试或监控证据。
- 每次灰度扩大前：确认没有触发停止条件。
- 正式切换后一周：每日复查 R01、R03、R04、R07、R08、R09 和 R12。

## 风险关闭规则

风险不能因为“最近没出现”直接删除。只有根因已消除、自动检测已覆盖并完成一次恢复或回滚演练后，才可标为关闭；关闭记录需保留日期和证据链接。
